# GLHIGA Website — Georgia Life & Health Insurance Guaranty Association

9 responsive pages. Every page is fully self-contained — all images, logos, and the
embedded PDF documents live inside each HTML file. No assets folder is required for
the pages to work; they link to each other by plain page name.

## Pages
| File | Page |
|------|------|
| index.html | Homepage |
| about-us.html | About Us |
| faqs.html | Frequently Asked Questions |
| receiverships.html | Receiverships |
| additional-information.html | Additional Information |
| insurance-companies.html | For Insurance Companies |
| links.html | Links |
| contact-us.html | Contact Us |
| terms-of-use.html | Terms of Use |

## Deploy
Upload the 9 .html files together to your web host. index.html is the homepage;
all navigation links use plain page names (e.g., about-us.html).

## source-assets/
The original logo/icon/photo files, provided only if you want to edit the artwork.
The pages do NOT need this folder — everything is already embedded.

## Note
Fonts load from Google Fonts (Montserrat) — the only external request.
